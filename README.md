## 📊 Task

**Task 2 - Exploratory Data Analysis (EDA)**

## 📖 Project Overview

This project was completed as part of the CodeAlpha Data Analytics Internship.

The objective of this task was to perform **Exploratory Data Analysis (EDA)** on the dataset generated during Task 1.

The analysis focuses on understanding the dataset, checking data quality, analyzing book prices and ratings, identifying patterns, and exploring relationships between variables.

## 🎯 Objectives

* Load and understand the dataset
* Check dataset structure and data types
* Identify missing values
* Check duplicate records
* Analyze book prices
* Analyze rating distribution
* Analyze book availability
* Identify the most and least expensive books
* Analyze the relationship between price and rating
* Identify potential price outliers
* Generate meaningful EDA visualizations

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## 📋 Dataset

The dataset contains information about books collected during Task 1.

The main columns are:

* **Title**
* **Price (INR)**
* **Rating**
* **Availability**

A numerical rating column was created by converting the rating values from words to numbers.

## 🔍 Analysis Performed

The following analysis was performed:

* Dataset shape and structure
* Column and data type analysis
* Statistical summary
* Missing value analysis
* Duplicate value analysis
* Rating distribution
* Average, minimum, and maximum price
* Top 10 most expensive books
* Top 10 cheapest books
* Availability analysis
* Price and rating correlation
* Potential price outlier analysis

## 📊 Visualizations

The following visualizations were created:

1. **Distribution of Book Ratings**
2. **Distribution of Book Prices**
3. **Book Price Distribution and Outliers**
4. **Price vs Rating**

The graphs were saved as high-resolution PNG images.
